# Bundled plotting records

These six CSV files are the default inputs for all included figures. They retain
the actual study values used in the plots, together with an integrity manifest.
The complete workbook and patient images are not part of this package.

In the repository checkout, see `data/README.md` at the project root for the
dataset and field dictionary. The Python loader uses package resources, so the
data also remain available after installation and from other working directories.
